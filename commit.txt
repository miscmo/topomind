    Add trash, attachment safety, and safe-quit
    
    Introduce comprehensive trash management and several security/robustness improvements: add trash APIs for kbs, attachments and topo-documents (list/restore/clear/delete), move deleted files to .trash with metadata; enforce attachment and text file size limits and block dangerous attachment extensions; validate and restrict HTTP(S) download targets (DNS lookup + private IP checks) to prevent local/SSRF access; require active workdir for FS IPC handlers; add safe path resolution/validation (no symlink imports, no path escapes), atomic JSON writes, and safer import/copy behavior; sanitize open-file dialog options and external URLs; add safe external open and window-close flow that confirms and flushes before quitting (requestSafeQuit/leaveWorkDir); small misc. IPC and file-service updates to use the new validations. These changes improve data integrity and mitigate security risks when handling files, attachments and external resources.
